# Task: Embedded Kestrel HTTP server with session endpoints

<description>

Implement the HTTP server that receives hook events from Claude Code sessions. This runs embedded inside the WPF process on a background thread, using ASP.NET Core Kestrel minimal API.

**HookServer service (`Services/HookServer.cs`):**
- Creates a `WebApplication` using `WebApplication.CreateSlimBuilder()`
- Configures Kestrel to bind to `http://127.0.0.1:22322`
- Registers endpoints (see below)
- Runs via `app.RunAsync()` (non-blocking)
- Implements `IDisposable` for clean shutdown
- Suppresses all ASP.NET Core console logging (no output to stdout/stderr)

**Endpoints:**
```
GET  /api/health                → 200 OK (empty body)
POST /api/session/start         → Registers new session
POST /api/session/update        → Updates session status/message/context
POST /api/session/notification  → Flags session as needing attention
POST /api/session/end           → Removes session
```

**Payload models (`Models/`):**

`SessionStartPayload`:
```csharp
public record SessionStartPayload(
    string session_id,
    string cwd,
    string? model,
    string? hook_event_name,
    string? timestamp);
```

`SessionUpdatePayload`:
```csharp
public record SessionUpdatePayload(
    string session_id,
    string? cwd,
    string? hook_event_name,
    string? last_assistant_message,
    bool? stop_hook_active,
    double? used_percentage,
    int? context_window_size,
    string? timestamp);
```

`SessionNotificationPayload`:
```csharp
public record SessionNotificationPayload(
    string session_id,
    string? notification_type,
    string? message,
    string? hook_event_name,
    string? timestamp);
```

`SessionEndPayload`:
```csharp
public record SessionEndPayload(
    string session_id,
    string? hook_event_name,
    string? timestamp);
```

**SessionManager service (`Services/SessionManager.cs`):**
- `ConcurrentDictionary<string, SessionInfo> ActiveSessions`
- Methods: `RegisterSession()`, `UpdateSession()`, `NotifySession()`, `RemoveSession()`
- Events: `SessionAdded`, `SessionUpdated`, `SessionRemoved` (for ViewModel binding)
- Each method validates `session_id` is non-null, ignores malformed payloads silently

**SessionInfo model (`Models/SessionInfo.cs`):**
```csharp
public class SessionInfo
{
    public string SessionId { get; set; }
    public string WorkingDirectory { get; set; }
    public string? Model { get; set; }
    public string? Title { get; set; }
    public string? LastMessage { get; set; }
    public SessionStatus Status { get; set; }
    public double ContextUsedPercentage { get; set; }
    public int ContextWindowSize { get; set; }
    public DateTime StartedUtc { get; set; }
    public DateTime LastUpdatedUtc { get; set; }
}

public enum SessionStatus { Working, Waiting, Error, Idle }
```

**Integration with WPF:**
- `HookServer` is started in `App.OnStartup()` before showing any window
- `SessionManager` is a singleton shared between the server and the ViewModel
- Events are marshalled to the UI thread via `Application.Current.Dispatcher.InvokeAsync()`
