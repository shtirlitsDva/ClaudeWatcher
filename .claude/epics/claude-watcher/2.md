# Task: WPF skeleton - borderless dark window with drag, single-instance, and tray icon

<description>

Create the foundational WPF application with all window chrome and lifecycle behavior. This is the shell that everything else plugs into.

**Project setup:**
- Create `ClaudeWatcher.sln` and `src/ClaudeWatcher/ClaudeWatcher.csproj`
- Target `net10.0-windows`
- Add NuGet references: `CommunityToolkit.Mvvm`, `H.NotifyIcon.Wpf`
- Set output type to `WinExe`

**Borderless dark window (`MainWindow.xaml`):**
- `WindowStyle="None"`, `AllowsTransparency="True"`, `Background="Transparent"`
- Outer `Border` with `CornerRadius="8"`, background `#1A1A2E`, subtle border `#2A2A3E`
- Semi-transparent: `Opacity="0.95"`
- `Topmost="True"`
- `SizeToContent="Height"`, fixed width 360px, `MaxHeight="600"` with `ScrollViewer`
- Drag anywhere: `MouseLeftButtonDown` handler calls `DragMove()`
- Starts invisible (`Visibility="Hidden"`) until first session registers

**Dark theme (`Resources/Theme.xaml`):**
- Color palette: background `#1A1A2E`, card background `#1E1E2E`, card hover `#252540`, text `#E0E0E0`, secondary text `#888888`
- Accent colors: yellow `#FFB800`, red `#FF4444`, green `#4CAF50`, blue `#2196F3`
- Default font: Segoe UI Variable, 13px
- Implicit styles for `TextBlock`, `Border`, `ScrollViewer` (dark scrollbar)

**Single-instance enforcement (`App.xaml.cs`):**
- Use a named `Mutex` (`ClaudeWatcher_SingleInstance`)
- If mutex already exists, find the existing window and bring it to front, then exit
- On exit, release mutex

**System tray (`App.xaml.cs` + `H.NotifyIcon`):**
- Tray icon using `H.NotifyIcon.Wpf` (`TaskbarIcon`)
- Left-click toggles window visibility
- Tray tooltip: "ClaudeWatcher"
- Icon: embed a simple dark-themed icon (can be a placeholder for now)

**MainViewModel:**
- `ObservableCollection<SessionCardViewModel> Sessions`
- `bool HasSessions` property (bound to window visibility)
- When `Sessions.Count` goes from 0 → 1, show window; from 1 → 0, hide window

</description>

<acceptance-criteria>

- [ ] `dotnet build` succeeds with zero errors
- [ ] App launches as a borderless, rounded-corner, dark window
- [ ] Window can be dragged by clicking anywhere on it
- [ ] Window is always-on-top
- [ ] Window starts hidden, can be shown/hidden programmatically
- [ ] Only one instance can run at a time (second launch brings first to front)
- [ ] System tray icon appears; left-click toggles window
- [ ] Window height adjusts to content, max 600px with scrolling

</acceptance-criteria>
