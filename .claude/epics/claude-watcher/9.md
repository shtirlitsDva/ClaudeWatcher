# Task: Settings persistence and Windows startup shortcut

<description>

Implement persistent application settings and the "Launch on Windows startup" feature. Settings are stored as a JSON file in the app's local data directory.

**Settings model (`Models/AppSettings.cs`):**
```csharp
public class AppSettings
{
    public bool LaunchOnStartup { get; set; } = false;
    public int HttpPort { get; set; } = 22322;
    public double WindowOpacity { get; set; } = 0.95;
    public int MaxWindowHeight { get; set; } = 600;
}
```

**Settings service (`Services/SettingsService.cs`):**
- Load from `%LOCALAPPDATA%/ClaudeWatcher/settings.json`
- Save on any change (debounced, 500ms delay to avoid excessive writes)
- Create directory and file if they don't exist (use defaults)
- Thread-safe (settings can be read from HTTP server thread)

**Windows startup shortcut (`Services/StartupService.cs`):**
- Toggle creates/removes a shortcut in `%APPDATA%/Microsoft/Windows/Start Menu/Programs/Startup/`
- Shortcut points to the current executable path
- Use `IWshRuntimeLibrary` (Windows Script Host) COM interop to create `.lnk` files:
  ```csharp
  var shell = new IWshShell_Class();
  var shortcut = (IWshShortcut)shell.CreateShortcut(shortcutPath);
  shortcut.TargetPath = Process.GetCurrentProcess().MainModule.FileName;
  shortcut.WorkingDirectory = AppContext.BaseDirectory;
  shortcut.Description = "ClaudeWatcher - Claude Code Session Monitor";
  shortcut.Save();
  ```
- Or use the simpler approach: `File.CreateSymbolicLink()` or just copy executable path to a `.bat` file in Startup
- Simplest reliable approach: use the registry key `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` instead of a shortcut file:
  ```csharp
  using var key = Registry.CurrentUser.OpenSubKey(
      @"Software\Microsoft\Windows\CurrentVersion\Run", true);
  if (enable)
      key.SetValue("ClaudeWatcher", $"\"{exePath}\"");
  else
      key.DeleteValue("ClaudeWatcher", false);
  ```

**Integration with settings UI (from task 007):**
- Bind the "Launch on Windows startup" toggle to `AppSettings.LaunchOnStartup`
- On toggle change: call `StartupService.SetStartup(bool)` and save settings
- On app startup: read settings and apply (port, opacity, max height)

**Port configuration:**
- If user changes port in settings, require app restart to take effect
- Show the current port as read-only in settings panel
- On startup, if configured port is in use, try next ports (22323-22330) and update the displayed port

**Window opacity:**
- Bind `MainWindow.Opacity` to `AppSettings.WindowOpacity`
- Slider in settings panel (range 0.5 to 1.0, step 0.05)

</description>

**Files to modify:**

- `src/ClaudeWatcher/ViewModels/MainViewModel.cs` — bind settings properties for UI
- `src/ClaudeWatcher/Services/HookServer.cs` — accept port from settings

**Registry approach for startup:**
Using `HKCU\...\Run` is the simplest and most reliable approach. It doesn't require admin rights and survives app path changes (as long as the path is updated).

**Settings file location:**
`%LOCALAPPDATA%/ClaudeWatcher/settings.json` — same directory as `recent-sessions.json`. Create the directory in `App.OnStartup()` if it doesn't exist.
