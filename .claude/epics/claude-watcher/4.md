# Task: Session card UI with status indicators, context bar, and animations

<description>

Build the session card `UserControl` that displays a single Claude Code session. Each card shows status, title, message snippet, context usage, elapsed time, and model badge. This is the core visual element of the app.

**SessionCard UserControl (`Views/SessionCard.xaml`):**

Layout (vertical stack inside a `Border`):
```
+----------------------------------------------------------+
|  [spinner/dot]  Session Title              [model] [time] |
|  Latest message from Claude, truncated to               |
|  two lines with ellipsis...                              |
|  [====================----------] context bar            |
+----------------------------------------------------------+
```

**Card container:**
- `Border` with `CornerRadius="6"`, background `#1E1E2E`, margin `0,0,0,6` (gap between cards)
- Hover effect: background transitions to `#252540` (via `Trigger` on `IsMouseOver`)
- Cursor changes to `Hand` on hover
- Padding: 12px all sides

**Status indicator (left side of title row):**
- 14x14px area
- **Working (spinner):** Use a `Path` (arc shape) with a continuous `RotateTransform` animation via `Storyboard`. Color: `#2196F3` (blue)
- **Waiting:** `Ellipse` fill `#FFB800` (yellow) with `DoubleAnimation` on `Opacity` from 1.0 to 0.3, `AutoReverse="True"`, `RepeatBehavior="Forever"`, duration 0.8s
- **Error:** `Ellipse` fill `#FF4444` (red) with same flashing animation as Waiting but faster (0.5s)
- **Idle:** `Ellipse` fill `#4CAF50` (green), solid, no animation

Status indicator switches via `DataTrigger` bound to `SessionCardViewModel.Status` enum.

**Title row:**
- Status indicator + Title `TextBlock` (SemiBold, 14px, `#E0E0E0`, `TextTrimming="CharacterEllipsis"`)
- Right side: model badge (`Border` with `CornerRadius="3"`, background `#2A2A3E`, padding `4,1`, text 10px `#888888`) + elapsed time `TextBlock` (12px, `#888888`)

**Message area:**
- `TextBlock` with `TextWrapping="Wrap"`, `MaxHeight="40"` (approx 2 lines), `TextTrimming="CharacterEllipsis"`
- Font 12px, color `#AAAAAA`
- If no message, show working directory path in italics

**Context usage bar:**
- `Grid` at the bottom of the card, height 3px, full width
- Background: `#151525` (track)
- Foreground: `Rectangle` with `HorizontalAlignment="Left"`, width bound to percentage of card width
- Color based on free context: green (`#4CAF50` at 60% opacity) >30% free, yellow (`#FFB800` at 60%) 10-30% free, red (`#FF4444` at 60%) <10% free
- Calculation: `FREE = (CTX - (CTX * usedPct / 100) - 33000) * 100 / CTX`

**SessionCardViewModel (`ViewModels/SessionCardViewModel.cs`):**
- Observable properties: `Title`, `Message`, `Status` (enum), `ModelName`, `ElapsedTime` (string), `ContextFreePercentage` (double), `ContextBarColor` (Brush)
- `DispatcherTimer` updating `ElapsedTime` every second (formats as "1m", "12m", "1h 23m", "2h+")
- `UpdateFrom(SessionInfo)` method to refresh all properties from the model
- Computed `DefaultTitle` from `WorkingDirectory` + git info (via `GitInfoHelper`)

**Animations resource dictionary (`Resources/Animations.xaml`):**
- Named storyboards for spinner rotation, yellow flash, red flash
- Reusable via `StaticResource` from `SessionCard.xaml`

**Spinner implementation detail:**
Use a `Path` drawing a 270-degree arc, animated with `RotateTransform`:
```xml
<Path Data="M 7,1 A 6,6 0 1 1 1,7" Stroke="#2196F3" StrokeThickness="2"
      RenderTransformOrigin="0.5,0.5">
    <Path.RenderTransform>
        <RotateTransform x:Name="SpinnerRotation" />
    </Path.RenderTransform>
</Path>
```
Animated via a `Storyboard` with `DoubleAnimation` on `SpinnerRotation.Angle` from 0 to 360, duration 1s, `RepeatBehavior="Forever"`.

**Context free % calculation in ViewModel:**
```csharp
public void UpdateContextBar(double usedPct, int windowSize)
{
    int used = (int)(windowSize * usedPct / 100);
    int free = (windowSize - used - 33000) * 100 / windowSize;
    free = Math.Max(0, Math.Min(100, free));
    ContextFreePercentage = free;
    ContextBarColor = free <= 10 ? RedBrush : free <= 30 ? YellowBrush : GreenBrush;
}
```
