# Task: Hook scripts - install/uninstall with tab title setting and auto-launch

<description>

Create the bash scripts that install and uninstall ClaudeWatcher hooks into the user's `~/.claude/settings.json`. The hooks must integrate cleanly with any existing hooks the user has configured, and must never pollute the Claude terminal with errors.

**Install script (`scripts/install-hooks.sh`):**

1. Read existing `~/.claude/settings.json` (or create if missing)
2. Parse the existing `hooks` object (preserve all existing hooks)
3. For each hook event (`SessionStart`, `Stop`, `Notification`, `SessionEnd`):
   - Check if a ClaudeWatcher hook already exists (by checking for the watcher URL in the command string)
   - If exists, update it in place
   - If not, append the watcher hook to the event's hook array
4. Write the updated settings back
5. Print confirmation

**Hook definitions to install:**

`SessionStart` hook (command type):
- Reads JSON from stdin
- Extracts `session_id`, takes first 8 chars as short ID
- Sets terminal tab title to `CW:{short_id}` via OSC escape sequence to `/dev/tty`
- Checks if watcher is running via `curl -sf http://127.0.0.1:22322/api/health`
- If not running, launches `ClaudeWatcher.exe` from `%LOCALAPPDATA%/ClaudeWatcher/` and waits 2 seconds
- POSTs the session start payload to the watcher
- Outputs `additionalContext` JSON telling Claude the session is being monitored
- All errors suppressed via `2>/dev/null` and `exit 0`
- Timeout: 10 seconds

`Stop` hook (command type):
- Reads JSON from stdin
- POSTs to `/api/session/update`
- All errors suppressed, always exits 0
- Timeout: 5 seconds

`Notification` hook (command type):
- Reads JSON from stdin
- POSTs to `/api/session/notification`
- All errors suppressed, always exits 0
- Timeout: 5 seconds

`SessionEnd` hook (command type):
- Reads JSON from stdin
- POSTs to `/api/session/end`
- All errors suppressed, always exits 0
- Timeout: 5 seconds (note: SessionEnd has a very short default timeout, so this must be fast)

**Uninstall script (`scripts/uninstall-hooks.sh`):**
1. Read `~/.claude/settings.json`
2. For each hook event, remove entries containing the watcher URL (`127.0.0.1:22322`)
3. If an event's hook array is now empty, remove the event key
4. If the hooks object is now empty, remove the hooks key
5. Write updated settings back
6. Print confirmation

**Critical requirements:**
- Scripts must use `jq` for JSON manipulation (safe, no regex hacking on JSON)
- Must preserve all existing hooks — never overwrite the entire hooks object
- Must handle the case where `settings.json` doesn't exist yet
- Must handle the case where `hooks` key doesn't exist yet
- Hook commands must work on Windows with Git Bash (which is what Claude Code uses)
- The `/dev/tty` approach for tab title setting must be tested — if it doesn't work on Windows, fall back to a no-op for title setting

**Context injection content (SessionStart additionalContext):**
```
ClaudeWatcher is monitoring this session. Focus on your work as normal.
```

Keep this minimal — don't overwhelm Claude with instructions. The main value is just the session registration, not Claude changing its behavior.

</description>

<technical-details>

**Files to create:**
- `scripts/install-hooks.sh`
- `scripts/uninstall-hooks.sh`

**jq dependency:** The scripts require `jq` for JSON manipulation. On Windows with Git Bash, jq may not be installed. Include a check at the top:
```bash
if ! command -v jq &>/dev/null; then
    echo "Error: jq is required. Install from https://jqlang.github.io/jq/download/"
    exit 1
fi
```

**Hook command template (SessionStart):**
```bash
bash -c 'input=$(cat); sid=$(echo "$input" | jq -r ".session_id // empty"); short=${sid:0:8}; echo -ne "\\033]0;CW:${short}\\007" > /dev/tty 2>/dev/null; curl -sf http://127.0.0.1:22322/api/health > /dev/null 2>&1 || (start "" "%LOCALAPPDATA%/ClaudeWatcher/ClaudeWatcher.exe" 2>/dev/null; sleep 2); curl -sf -X POST http://127.0.0.1:22322/api/session/start -H "Content-Type: application/json" -d "$input" > /dev/null 2>&1; echo "{\"additionalContext\": \"ClaudeWatcher is monitoring this session. Focus on your work as normal.\"}"; exit 0'
```

**Testing:**
After installing hooks, start a new Claude session and verify:
1. Watcher receives the session start event
2. Tab title changes (or doesn't — `/dev/tty` may not work)
3. No errors visible in Claude terminal
4. Subsequent stop/notification/end events are received

</technical-details>
