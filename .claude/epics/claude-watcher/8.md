# Task: Right-click context menu with recent sessions, new session, and settings

<description>

Implement the right-click context menu for both the main window and the system tray icon. Includes the recent sessions list, new session launcher, settings panel, and minimize/exit controls.

**Context menu structure:**
```
+-----------------------------------+
| Recent Sessions               >   |
|   MyProject - master    2h ago    |
|   OtherRepo - feat/x   yesterday |
|   ...                             |
+-----------------------------------+
| New Session...                    |
+-----------------------------------+
| Settings...                       |
+-----------------------------------+
| Minimize to Tray                  |
| Exit                              |
+-----------------------------------+
```

**Context menu styling:**
- Dark background `#1E1E2E`, border `#2A2A3E`, corner radius 6px
- Menu items: text `#E0E0E0`, hover background `#252540`
- Separator lines: `#2A2A3E`
- Font: Segoe UI Variable, 13px
- Override default WPF `ContextMenu` style in `Theme.xaml`

**Recent Sessions (`Services/RecentSessionsService.cs`):**
- Persists to `%LOCALAPPDATA%/ClaudeWatcher/recent-sessions.json`
- Stores last 20 sessions (FIFO, oldest dropped)
- Each entry:
  ```csharp
  public record RecentSession(
      string ProjectName,
      string FolderPath,
      string? Branch,
      string? WorktreeName,
      DateTime LastActiveUtc);
  ```
- On `SessionEnd`, save session info to recent list
- On `SessionStart`, update existing entry's `LastActiveUtc` if folder matches
- Display format in menu: "ProjectName - Branch   timeAgo"

**Clicking a recent session:**
1. Open a new Windows Terminal tab in that directory
2. Launch `claude` in that tab
3. Command: `wt.exe new-tab --startingDirectory "<folder>" -- claude`
4. If `wt.exe` is not available, fall back to: `start cmd /k "cd /d <folder> && claude"`

**New Session:**
1. Open a `FolderBrowserDialog` (or WPF-friendly folder picker via `Microsoft.Win32.OpenFolderDialog` on .NET 10)
2. If user selects a folder, launch Claude in that folder (same as recent session click)

**Settings panel:**
Rather than a separate window, use a `Popup` or an expandable section in the main window:
- **"Launch on Windows startup"** toggle (`ToggleButton` or custom switch)
  - Implementation deferred to task 008
  - For now, just the UI control bound to a `bool` property
- **Port display** (read-only, shows current port like "Port: 22322")
- Dark-styled to match the rest of the app

**Minimize to Tray:**
- Hides the window (`Visibility.Hidden`)
- Tray icon remains visible
- Left-click on tray icon restores window

**Exit:**
- Shuts down the HTTP server
- Releases the single-instance mutex
- Calls `Application.Current.Shutdown()`

**Tray icon context menu:**
Same menu as the main window right-click, reused via a shared resource or view model.

</description>

**Relative time formatting:**
```csharp
string FormatTimeAgo(DateTime utc)
{
    var span = DateTime.UtcNow - utc;
    if (span.TotalMinutes < 60) return $"{(int)span.TotalMinutes}m ago";
    if (span.TotalHours < 24) return $"{(int)span.TotalHours}h ago";
    if (span.TotalDays < 7) return $"{(int)span.TotalDays}d ago";
    return utc.ToLocalTime().ToString("MMM d");
}
```
